# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
- Объём оперативной памяти: 2048 МБ
- Количество ядер процессора: 2
- Объём дискового накопителя: 25 ГБ, динамически расширяемый
- Тип и версия гостевой ОС: Linux / Ubuntu Server 24.04 LTS (64-bit)
- Имя узла: `devops-vm`
- Полное доменное имя (FQDN): `devops-vm.devops.local`

## 2. Сетевые интерфейсы
| Адаптер | Тип | Полученный адрес | Назначение |
|---------|-----|------------------|------------|
| 1 | NAT | `10.0.2.15` | Доступ гостевой системы в Интернет (репозитории пакетов), входящие соединения — только через проброс портов |
| 2 | Host-only (VirtualBox Host-Only Ethernet Adapter) | `192.168.56.101` | Прямой доступ с хостовой системы к гостевой, используется для обращения по имени `devops.local` и в последующих практических работах |

## 3. Правило проброса портов
- Порт хостовой системы: `2222`
- Порт гостевой системы: `2222` (изменён с `22` после усиления SSH)
- Назначение: подключение к службе SSH виртуальной машины с хостовой системы по адресу `127.0.0.1:2222`.

## 4. Учётные записи
| Имя | Группы | Способ аутентификации | Примечание |
|-----|--------|------------------------|------------|
| `student` | `student`, `sudo` | Пароль | Создана при установке ОС; используется для первичной настройки и выполнения `sudo` |
| `devops` | `devops`, `sudo` | Ключ SSH (`~/.ssh/devops_vm`) | Создана для удалённого администрирования; парольная аутентификация отключена, вход разрешён только по ключу |

## 5. Служба SSH
- Порт: `2222`
- Расположение файла конфигурации: `/etc/ssh/sshd_config.d/99-hardening.conf` (дополняющий файл; основной `/etc/ssh/sshd_config` не изменялся)
- Изменённые директивы и их значения:
  - `Port 2222`
  - `PermitRootLogin no`
  - `PasswordAuthentication no`
  - `PubkeyAuthentication yes`
  - `PermitEmptyPasswords no`
  - `MaxAuthTries 3`
  - `LoginGraceTime 30`
  - `AllowUsers devops`
  - `X11Forwarding no`
  - `ClientAliveInterval 300`
  - `ClientAliveCountMax 2`
- Дополнительно: отключена активация по сокету (`ssh.socket`), служба запускается через `ssh.service`; в `/etc/ssh/sshd_config.d/` проверено отсутствие конфликтующей директивы `PasswordAuthentication yes` (например, в `50-cloud-init.conf`).

## 6. Правила межсетевого экрана
- Политики по умолчанию:
  - Входящий трафик: `deny`
  - Исходящий трафик: `allow`
- Перечень правил:
  - `allow 80/tcp` (HTTP)
  - `allow 443/tcp` (HTTPS)
  - `limit 2222/tcp` (SSH с ограничением частоты подключений, признак `LIMIT` в выводе `ufw status verbose`)
- Состояние: `active`
- Включена регистрация событий: `ufw logging medium`

## 7. Снимки состояния
| Наименование | Момент создания |
|--------------|-----------------|
| `01-clean-install` | После установки ОС, обновления пакетов и проверки сетевых интерфейсов (до создания учётной записи `devops` и настройки ключей) |
| `02-keys-configured` | После создания пользователя `devops`, настройки ключевой аутентификации и файла `~/.ssh/config` на хостовой системе |
| `03-ssh-hardened` | После усиления конфигурации SSH (порт 2222, отключение root-входа и парольной аутентификации, ограничение `MaxAuthTries`) и успешной проверки нового подключения |
