1. В Git ветвление является дешёвым, так как ветка представляет собой локальный текстовый файл с указателем на коммит, в то время как в SVN создание веток требует сетевого обращения к центральному серверу.

2. Выполнение коммита без интернет-соединения в SVN невозможно из-за его централизованной архитектуры, хранящей всю историю на удаленном сервере.

3. SVN может быть предпочтительнее Git при работе с бинарными и тяжелыми файлами, необходимости частичного скачивания репозитория, жестком разграничении прав доступа, эксклюзивной блокировке файлов и простоте освоения для неразработчиков.
